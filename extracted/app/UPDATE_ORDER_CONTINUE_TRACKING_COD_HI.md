# Sanchore Bazaar – ऑर्डर, Continue और COD अपडेट

इस अपडेट में ये बदलाव किए गए हैं:

1. **कार्ट Continue बार:** कार्ट स्क्रीन के नीचे आइटम की संख्या, कुल रकम और बड़ा CONTINUE बटन दिखता है। इससे ग्राहक ऑफर → डिलीवरी पता → भुगतान के चरणों में आगे बढ़ता है।
2. **ऑर्डर ट्रैकिंग बार:** ऑर्डर करने के बाद ग्राहक होम स्क्रीन के सबसे नीचे सक्रिय ऑर्डर की स्थिति देख सकता है। बार दबाने पर पूरा लाइव ऑर्डर ट्रैकिंग पेज खुलता है।
3. **Admin COD सूची:** ग्राहक और स्वीकृत दुकानों की सूची अब Cloudflare Worker के सुरक्षित Admin API से आती है। हर ग्राहक और हर दुकान के लिए अलग COD स्विच और सूची रीफ्रेश बटन है।
4. **Checkout COD जाँच:** COD विकल्प तभी दिखेगा जब ग्लोबल सेटिंग, ग्राहक खाता और कार्ट की सभी दुकानें COD की अनुमति दें। सर्वर पर भी अंतिम जाँच मौजूद है।

## FlutLab में अपडेट
- इस ZIP को FlutLab में इम्पोर्ट करके Android Build चलाएँ।
- इस ZIP में `cloudflare-worker/worker.js` भी अपडेट है। Cloudflare Dashboard में अपने Worker का कोड इसी फाइल से पूरा बदलकर Deploy करें।
- Worker Deploy और ऐप Build दोनों पूरे होने के बाद Admin Panel → पेमेंट और COD कंट्रोल → ग्राहक और दुकानदार का COD नियंत्रण खोलकर सूची जाँचें।

**ध्यान दें:** इस वातावरण में Flutter SDK उपलब्ध नहीं था, इसलिए Android APK/Flutter compile का परीक्षण नहीं किया जा सका। Worker JavaScript की syntax जाँच की गई है।
