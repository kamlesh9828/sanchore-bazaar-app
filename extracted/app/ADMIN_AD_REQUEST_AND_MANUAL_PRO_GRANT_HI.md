# Sanchore Bazaar – विज्ञापन रिक्वेस्ट और Admin Pro सुविधा

## दुकानदार विज्ञापन रिक्वेस्ट
- दुकानदार पैनल में विज्ञापन रिक्वेस्ट भेजने का विकल्प उपलब्ध है।
- दुकानदार व्यवसाय का नाम, मोबाइल, प्रचार विवरण और वैकल्पिक फोटो भेज सकता है।
- एडमिन विज्ञापन प्रबंधन स्क्रीन में रिक्वेस्ट देख सकता है, अस्वीकार कर सकता है या उससे विज्ञापन ड्राफ्ट बना सकता है।
- स्वीकृत विज्ञापन का भुगतान और सक्रियण मौजूदा Paytm सत्यापन प्रक्रिया से होता है।

## Admin द्वारा Pro देना
- Admin Pro नियंत्रण में सभी स्वीकृत और सक्रिय दुकानों की सूची दिखाई जाती है।
- Admin किसी दुकान को 30, 90, 180 या 365 दिन की Pro सदस्यता दे सकता है।
- पहले से वैध Pro सदस्यता होने पर नई अवधि मौजूदा समाप्ति तारीख के बाद जुड़ती है।
- Admin द्वारा दी गई सदस्यता का भुगतान ₹0 और paymentStatus `admin_granted` से अलग रिकॉर्ड होता है; इसे Paytm आय में नहीं जोड़ा जाता।
- Admin सदस्यता रोक और वैध अवधि रहते बहाल भी कर सकता है।
- सभी अधिकार-जाँच Cloudflare Worker में Admin role के साथ की जाती है।

## Deploy
`cloudflare-worker/worker.js` को Cloudflare Worker `sanchore-bazaar-api` में अपडेट करके Deploy करें। इसके बाद ऐप का नया Flutter build बनाकर इंस्टॉल करें।

## नई दुकान जोड़ने की रिक्वेस्ट (इस अपडेट में)
- दुकानदार केवल रिक्वेस्ट भेज सकता है; सीधे दुकान बनाना बंद है।
- Admin की मंजूरी पर ही Worker `shops` में दुकान बनाता है।
- रिजेक्ट करने पर Admin कारण लिखता है और दुकानदार उसे अपने पैनल में देखता है।
